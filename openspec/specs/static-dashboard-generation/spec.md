# static-dashboard-generation Specification

## Purpose

Define the no-server static dashboard generated from Growth Knowledge Hub's local Wiki index.

## Requirements

### Requirement: Generate a no-server static dashboard
The system SHALL generate a static dashboard that can be opened directly from disk without starting a local web server.

#### Scenario: Dashboard command runs
- **WHEN** the host CLI or user runs `gkh.py dashboard`
- **THEN** the script writes an HTML entry file under the resolved data home dashboard directory

#### Scenario: Dashboard is opened from disk
- **WHEN** the user opens the generated HTML file in a browser
- **THEN** the dashboard renders without requiring a backend service

### Requirement: Build dashboard from the local index
The dashboard SHALL present skill-managed Wiki page metadata from the rebuilt local index.

#### Scenario: Wiki pages exist
- **WHEN** dashboard generation runs after capture, ingest, or review pages have been written
- **THEN** the dashboard shows page titles, summaries, paths, and page count derived from indexed Wiki pages

### Requirement: Exclude unsafe raw content
The dashboard MUST avoid embedding raw source bodies, local-only content, or secret values.

#### Scenario: Dashboard data is built
- **WHEN** dashboard generation reads local Wiki data
- **THEN** it uses sanitized index data and HTML escapes rendered values

### Requirement: Work without package installation
The dashboard SHALL be generated by the bundled skill script.

#### Scenario: Repository package is not installed
- **WHEN** `gkh.py dashboard` runs from the skill directory or repository path
- **THEN** it builds the dashboard using bundled standard-library code only
